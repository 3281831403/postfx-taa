# postfx-taa

## 题面

开 TAA 后静止画面还在抖、走路的人后面拖着影子：抖动序列固定为 (0, 0)，TAA 完全无效；抖动幅度超过 1 像素，画面轻微位移；重投影不按运动矢量，历史错位；重投影边界不 clamp，边缘黑边；不裁剪历史，运动物体拖影；方差裁剪用全局 sigma，静止区也被裁；alpha 固定 0.5，运动区糊、静止区抖；残影指标按全帧平均，局部残影检测不到；批量共用历史缓冲，帧之间串；尺寸不一致不报错，索引越界。taa/resolve.py 是核心，tests/test_resolve.py 15个红。要修的是：① 抖动序列逐帧变化（Halton/网格），不再固定 (0, 0)；② 抖动幅度归一化到 1 像素以内；③ 重投影按运动矢量做反向采样；④ 边界 clamp 到最近合法像素，禁止用 0 填充；⑤ 每个像素用当前帧邻域做方差裁剪，去掉错位历史；⑥ 裁剪使用局部 sigma，静止区保持原值；⑦ 混合权重改为 alpha/(1+|motion|)，静止区历史权重大、运动区小；⑧ 残影指标取局部 3x3 窗口有效残差均值的最大值；⑨ 批量逐帧串行，每帧使用独立历史缓冲；⑩ 尺寸/NaN/alpha 越界统一校验并抛 TaaError，批量任一帧非法时整体回滚。

## 运行方式

在仓库根目录运行：

```powershell
cd D:\gsb-20261119\postfx-taa
python -m pytest tests -q
```

初始失败环境必须恰好是：

```text
15 failed
```

输出尾部应为 `15 failed in ...s`，且没有 collection error、import error 或 syntax error。只需要 Python 3 和 pytest；全部离线，无外部依赖、无随机数、无 sleep。

## 验收基线

`tests/test_resolve.py` 是验收基线，不得修改、删除或弱化其中任何测试。实现只改 `taa/resolve.py`，保持公开函数签名、像素/运动矢量契约、图像 `list[list[float]]` 表示、`alpha` 权重 0..1 以及 `TaaError` 语义；所有像素与权重比较的默认绝对容差为 `1e-6`。图像中 `img[y][x]` 先行后列，运动矢量 `(dx, dy)` 以像素为单位。
